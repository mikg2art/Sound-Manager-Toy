## **Sound System**

This sound and music system was developed for the student semester project, Muramasa Burden.

You can play Muramasa Burden game on Steam: https://store.steampowered.com/app/3106200/Muramasa_Burden/

This project serves as a demonstration of the system's functionality and is playable within the Unity editor, where the sound and music implementation code are accessible.

Sound effects used in the project were created by Erik Dekker, Niklas Dietl and Fatemeh Falsafi.
